# Security Policy

At YBR Digital, we take the security of **MobCam** and the privacy of our users seriously. We appreciate the responsible disclosure of security vulnerabilities by security researchers, developers, and users.

---

## Supported Versions

Only the latest release of the MobCam OBS Studio Plugin receives active security fixes and updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

If you discover a security vulnerability in the MobCam OBS Studio Plugin, public website, or network protocol:

1. **Do not open a public issue.** Please report security issues confidentially.
2. Email full vulnerability details to our security team:  
   **[info@ybrdigital.in](mailto:info@ybrdigital.in)**
3. Please include:
   - A description of the issue and potential impact.
   - Exact steps or proof-of-concept (PoC) to reproduce the vulnerability.
   - Affected plugin version, OBS Studio version, and OS details.
   - Any suggested mitigations or patches if available.

---

## Response Process

- We will acknowledge receipt of your vulnerability report within **48 hours**.
- We will work diligently to confirm, mitigate, and issue a patched release.
- We request that you follow coordinated disclosure practices and refrain from publicly discussing or exploiting the vulnerability until a fix has been officially released.
